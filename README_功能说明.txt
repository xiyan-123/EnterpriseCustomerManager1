企业客户管家 - 重构版功能说明

一、核心定位
本版本已从“联系人导入工具”重构为“企业客户管理系统 + 手机通讯录同步工具 + Excel导入导出工具”。
核心对象为企业，唯一识别标志为公司名称。

二、已实现核心规则
1. 公司名称为唯一识别标志，导入重复企业时合并补充，不覆盖已有字段。
2. 客户状态默认为“未设置”，不会从Excel导入，只能在App内手动设置为：关注、跟进、重点。
3. Excel采用宽松导入：只要存在“公司名称/企业名称/单位名称”等列即可导入。
4. 支持宽表字段：分组、公司名称、所属行业、参保人数、区域、地址、联系人1/电话1、联系人2/电话2、备注1、标签1等。
5. 一个企业支持多个联系人、多个电话、多个备注、多个标签。
6. 导入手机通讯录时名称为：公司名称-联系人姓名；无联系人姓名时自动生成公司名称-联系人1。
7. 通讯录页可查看本App导入的联系人，并可同步删除手机通讯录中的对应联系人。
8. 删除通讯录时只删除本App导入且记录了系统RawContactId的联系人，不主动删除手机原有联系人。
9. 搜索支持全字段模糊搜索，输入1个字即可搜索公司、联系人、电话、区域、行业、标签、备注。
10. Excel导出为xlsx宽表，联系人、备注、标签列会根据当前导出范围自动扩展。

三、页面结构
底部五个页面：
1. 首页：统计看板、快捷导入、新增企业、批量导入、导出、状态入口。
2. 客户：企业列表、模糊搜索、状态筛选、分组筛选、企业详情。
3. 通讯录：查看已导入联系人、同步删除、批量导入。
4. 导入导出：导入Excel、导出全部/条件客户、下载模板。
5. 我的：规则说明、分组管理、清空数据。

四、导入Excel建议表头
序号、分组、公司名称、所属行业、参保人数、区域、地址、联系人1、电话号码1、联系人2、电话号码2、备注1、备注2、标签1、标签2

五、GitHub Actions云端打包
上传项目后进入 Actions -> Build Android APK -> Run workflow。
打包成功后下载 Artifacts 中的 enterprise-customer-manager-debug-apk，解压得到 app-debug.apk。

六、注意事项
1. 第一次导入/删除通讯录需要授予通讯录权限。
2. 本版本不做通话结束自动短信功能，该功能作为后续升级模块。
3. 数据保存在手机本地，不需要登录，不上传服务器。
